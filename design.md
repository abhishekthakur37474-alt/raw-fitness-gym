# RAW FIT GYM — PREMIUM FITNESS FRANCHISE WEBSITE

Build a **premium, production-quality, fully responsive fitness/gym franchise website** for **RAW FIT GYM** using:

* PHP
* Bootstrap 5
* HTML5
* CSS3
* Vanilla JavaScript
* Bootstrap Icons or another lightweight icon library

Do NOT use React, Next.js, Vue, Tailwind, or any frontend framework other than Bootstrap.

The website must feel like it was designed by a **high-end fitness branding agency**, not generated by AI.

---

Brand:

**RAW FIT GYM**

Positioning:

**Premium Fitness • Premium Experience • Scalable Business**

The website is primarily for **gym franchise enquiries**, while still feeling like a real premium fitness brand.

The visual direction should be inspired by the supplied RAW FIT GYM franchise presentation:

* Luxury
* Premium
* Athletic
* Strong
* Masculine

* Black + gold

Do NOT make it look like a SaaS website.

Do NOT make it look like a generic AI-generated landing page.

# 3. TYPOGRAPHY

Do NOT use the usual:

* Inter everywhere
* Poppins everywhere
* Roboto everywhere

Use a more distinctive premium editorial + athletic combination.

Recommended:

### Headings

**Bebas Neue** or **Barlow Condensed**

Use large uppercase typography for major headings.

### Body

**Manrope** or **DM Sans**

Body text should remain extremely readable.

Use:

* Condensed bold headings
* Clean modern body typography
* Large numeric typography
* Letter spacing
* Uppercase micro labels

Example:

RAW FIT

GYM

should feel bold and athletic rather than corporate.

Typography hierarchy must be strong.
